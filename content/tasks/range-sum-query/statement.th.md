# ผลรวมของช่วงข้อมูล

กำหนดอาร์เรย์ของจำนวนเต็ม `n` จำนวน และคำถาม `q` คำถาม แต่ละคำถามให้ดัชนี `l` และ `r`
(นับจาก 1 และรวมทั้งสองตำแหน่ง) จงหาผลรวมของสมาชิกอาร์เรย์ตั้งแต่ตำแหน่ง `l` ถึง `r` สำหรับทุกคำถาม

## รูปแบบข้อมูลเข้า

```
n q
a1 a2 ... an
l1 r1
...
lq rq
```

- `1 <= n, q <= 200000`
- `-10^9 <= ai <= 10^9`
- `1 <= l <= r <= n`

## รูปแบบข้อมูลออก

พิมพ์ `q` บรรทัด บรรทัดละคำตอบ

## ตัวอย่าง

ข้อมูลเข้า:

```
5 2
3 1 4 1 5
1 3
2 5
```

ข้อมูลออก:

```
8
11
```

## สิ่งที่โจทย์นี้สอน

การบวกทีละสมาชิกในแต่ละช่วงใช้เวลา `O(n*q)` ซึ่งช้าเกินไปเมื่อเทียบกับข้อจำกัดข้างต้น
อาร์เรย์ผลรวมสะสม (prefix sum) ตอบแต่ละคำถามได้ใน `O(1)` หลังจากเตรียมข้อมูล `O(n)`
จุดสำคัญของโจทย์คือการมองเห็นว่าต้นทุนถูกย้ายจากการตอบคำถามไปอยู่ที่การเตรียมข้อมูล
