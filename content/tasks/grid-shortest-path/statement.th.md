# เส้นทางสั้นที่สุดในตาราง

กำหนดตารางขนาด `n` แถว `m` คอลัมน์ แต่ละช่องเป็นช่องว่าง (`.`) หรือช่องกีดขวาง (`#`)
เริ่มที่ช่อง `(sr, sc)` และต้องการไปถึงช่อง `(tr, tc)` ในการก้าวหนึ่งครั้งสามารถเดินขึ้น ล่าง ซ้าย
หรือขวา ไปยังช่องว่างที่อยู่ติดกันได้ จงหาจำนวนก้าวที่น้อยที่สุด หรือพิมพ์ `-1` ถ้าไปไม่ถึง

## รูปแบบข้อมูลเข้า

```
n m
แถวของตาราง จำนวน n แถว แต่ละแถวยาว m
sr sc
tr tc
```

- `1 <= n, m <= 1000`
- ช่องเริ่มต้นและช่องเป้าหมายเป็นช่องว่างเสมอ

## รูปแบบข้อมูลออก

จำนวนเต็มหนึ่งจำนวน คือจำนวนก้าวที่น้อยที่สุด หรือ `-1`

## ตัวอย่าง

ข้อมูลเข้า:

```
3 4
....
.#..
....
1 1
3 4
```

ข้อมูลออก:

```
5
```

## สิ่งที่โจทย์นี้สอน

เมื่อทุกก้าวมีต้นทุนเท่ากัน การค้นหาแบบกว้าง (BFS) จะเยี่ยมชมช่องตามลำดับระยะทางที่ไม่ลดลง
ดังนั้นครั้งแรกที่ไปถึงเป้าหมายคือคำตอบที่ดีที่สุด ความผิดพลาดสองอย่างที่โจทย์นี้ออกแบบมาเพื่อจับคือ
การลืมใส่ช่องเริ่มต้นลงในคิวก่อนเริ่มลูป และการทำเครื่องหมายว่าเยี่ยมชมแล้วตอนนำออกจากคิว
แทนที่จะทำตอนใส่เข้าคิว
